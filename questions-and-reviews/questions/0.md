Consider the code in this program below:

```js
function calculateSum(a, b) {
  return a + b;
}

function logSum(a, b) {
  console.log(a + b);
}

const result1 = calculateSum(10, 32);
const result2 = logSum(10, 32);
```

a) what will `result1` evaluate to? Explain your answer

b) What will `result2` evaluate to? Explain your answer

c) Try to summarise the main difference between `logSum` and `calculateSum`


{YOUR ANSWERS HERE}

a) The answer is 42, according to the function calculateSum().

b) The answer will be 10 + 32. The addition will not happen, only this will get logged into the console.

c) CalculateSum() will actually work as a function, so it will do the calculation and return the result, but logSum() will only log (a + b) into the console.*/
